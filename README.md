# ☀️ 아침 뉴스 브리핑

매일 **오전 7시**, 한국 뉴스를 중심으로 미국 등 외신 뉴스까지 AI(Google Gemini, 무료)가 정리해 **카카오톡**으로 보내드립니다.
전체 내용은 웹페이지에서 볼 수 있고, 링크를 다른 사람에게 공유하면 누구나 바로 볼 수 있습니다.

## 매일 받는 것

| 카톡 | 내용 |
|---|---|
| ① | 날짜, 환율·금리·유가·금·비트코인 지표, 오늘의 핵심 3줄 |
| ②~⑤ | 증시·경제 / 정치·국제 / IT·AI / 사회·생활 헤드라인 |
| ⑥ | 오늘의 시사점 + 오늘의 일정 |

모든 카톡의 **[전체 브리핑 보기]** 버튼을 누르면 웹페이지가 열립니다.
웹페이지에는 국내 vs 외신 시각 비교, 관심 키워드 추적, 기사 원문 링크, 지난 브리핑이 있습니다.

## 자주 하는 일

### 관심 키워드·언론사 바꾸기
1. GitHub에서 이 저장소의 `config.yaml` 파일을 엽니다.
2. 오른쪽 위 연필(✏️) 버튼을 누르고 `keywords:` 아래 줄을 고칩니다. 줄 앞 공백은 그대로 두세요.
3. 아래쪽 **Commit changes** 버튼을 누르면 다음 날 브리핑부터 적용됩니다.

### 지금 바로 브리핑 받아보기 (테스트)
1. 저장소 위쪽 **Actions** 탭으로 갑니다.
2. 왼쪽에서 **아침 뉴스 브리핑**을 선택합니다.
3. **Run workflow** → 초록색 **Run workflow** 버튼을 누릅니다. 5~10분 뒤 카톡이 옵니다.

### 잠시 멈추기 / 다시 켜기
**Actions** 탭 → **아침 뉴스 브리핑** → 오른쪽 위 `···` → **Disable workflow**를 누릅니다. 다시 켤 때는 **Enable workflow**를 누릅니다.

### 다른 사람에게 공유하기
카톡으로 온 브리핑의 [전체 브리핑 보기]를 누른 뒤, 브라우저 주소를 복사해 보내면 됩니다. 매일 최신 브리핑 주소: https://wiohworkson-sketch.github.io/news-briefing/

## 문제가 생겼을 때
- 브리핑을 만들다 실패하면 **"⚠️ 오늘 아침 브리핑을 만들지 못했습니다"** 카톡이 옵니다. 버튼을 누르면 실행 기록(오류 내용)이 보입니다.
- 카톡이 아예 오지 않으면 카카오 로그인이 만료됐을 수 있습니다. 보통은 자동으로 연장되지만, 문제가 생기면 PC에서 `python setup.py`를 다시 실행하세요.
- 해결이 어려우면 Claude에게 오류 화면을 보여주며 물어보세요.

## 비용: 전부 무료
- AI 요약은 **Google Gemini 무료 버전**을 씁니다(하루 1회 사용으로 무료 한도 안). 카드를 등록하지 않았으므로 요금이 나가지 않습니다.
- GitHub 자동 실행, 카카오톡, 웹페이지도 무료입니다.
- 참고: 구글 무료 버전은 입력 내용(공개 뉴스 기사)이 구글 서비스 개선에 쓰일 수 있고, 구글이 무료 정책을 바꿀 수 있습니다.

## 구성 (참고용)
| 파일 | 하는 일 |
|---|---|
| `config.yaml` | 키워드·분야·지표·언론사 설정 (여기만 고치면 됨) |
| `briefing/collect.py` | 언론사 RSS에서 지난 26시간 기사 수집 |
| `briefing/markets.py` | 환율·금리·원자재·코인 지표 |
| `briefing/summarize.py` | Gemini가 분류·요약·시사점·일정 정리 |
| `briefing/publish.py` | 브리핑을 `docs/`(웹페이지)에 저장 |
| `briefing/kakao.py` | 카카오톡 나에게 보내기, 로그인 자동 연장 |
| `.github/workflows/daily-briefing.yml` | 매일 06:30 시작 → 07:00 발송 예약 |
| `setup.py` | 최초 1회 키 입력·카카오 연결 도우미 |

API 키는 GitHub의 암호화된 **Secrets**에만 저장되며 공개되지 않습니다. 카카오 로그인 정보도 암호화되어 저장됩니다. 브리핑 웹페이지는 공유하기 쉽도록 비밀번호 없이 공개됩니다.
